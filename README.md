# بوت تحليل شارت الذهب - دليل التشغيل السريع

## 1) تجهيز البوت على تيليجرام
1. افتح محادثة مع **@BotFather** على تيليجرام.
2. اكتب `/newbot` واتبع التعليمات (اسم البوت + username ينتهي بـ `bot`).
3. هياديك **توكن** (سلسلة طويلة). احفظه.

## 2) معرفة رقم الـ User ID بتاعك (عشان تكون أدمن)
1. افتح محادثة مع **@userinfobot** على تيليجرام.
2. هيبعتلك رقم الـ ID بتاعك. احفظه.

## 3) تجهيز مفتاح Gemini API (مجاني بالكامل)
اطلب مفتاح API من aistudio.google.com/apikey (باقة مجانية بدون بطاقة ائتمان).

## 4) تثبيت المكتبات
افتح الترمينال داخل مجلد المشروع واكتب:
```
pip install python-telegram-bot google-generativeai --upgrade
```

## 5) تعبئة الإعدادات
افتح ملف `bot.py` وعدّل القيم دي في الأعلى:
```python
TELEGRAM_BOT_TOKEN = "التوكن اللي أخذته من BotFather"
GEMINI_API_KEY = "مفتاح Gemini API"
ADMIN_ID = 123456789  # رقمك من userinfobot
WALLET_LINK = "رابط محفظتك على شام كاش"
SUBSCRIPTION_PRICE = "50000 ل.س"
```

أو (أفضل أمانًا) خليها متغيرات بيئة بدل ما تكتبها بالكود مباشرة:
```
export TELEGRAM_BOT_TOKEN="..."
export GEMINI_API_KEY="..."
export ADMIN_ID="123456789"
export WALLET_LINK="..."
```

## 6) التشغيل
```
python3 bot.py
```
لو ظهرت رسالة "البوت شغال..." يبقى تمام، جرب تفتح محادثة مع بوتك وابعت `/start`.

## آلية العمل (تذكير)
- مستخدم جديد → `/subscribe` → يوصله رابط محفظتك والسعر.
- يحوّل ويبعت صورة الإيصال → توصلك نسخة منها كأدمن مع أمر جاهز `/approve <user_id>`.
- ترسل `/approve <user_id>` → يتفعّل اشتراكه 30 يوم تلقائيًا.
- بعد كده، أي صورة شارت يبعتها المشترك تتحلل تلقائيًا بالـ AI.

## لتشغيل البوتين مع بعض على نفس اللابتوب
افتح البوت التاني (بوت التوصيات) بنافذة/طرفية منفصلة، وشغّل هذا البوت بطرفية تانية. كل واحد له عملية مستقلة.

## الخطوة الجاية (لما يكبر المشروع)
انقل الكود لاستضافة مجانية زي Render أو Railway عشان يشتغل 24 ساعة بدون ما تسيب اللابتوب مفتوح.
